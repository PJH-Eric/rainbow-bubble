# 彩虹泡泡砲

彩虹泡泡砲是可離線遊玩的泡泡射擊遊戲，只保留「單機」與「闖關」兩種模式。

## 遊玩方式

- 單機：一個人自由遊玩，可設定盤面、主題與時間。
- 闖關：挑戰分段關卡，進度和紀錄保存在目前裝置的瀏覽器。
- 開啟 `啟動遊戲.bat`，或直接用瀏覽器開啟 `public/index.html`。

## 開發與檢查

- `npm test`：執行單機規則、介面語系、分析與闖關測試。
- `npm run verify`：執行完整 Node 測試及 SEO 檢查。
- `npm run test:all`：執行 Node 與瀏覽器檢查；瀏覽器檢查需要環境提供 Playwright。
- `npm run test:quest`：執行闖關規則及關卡資料檢查。

部署使用 GitHub Pages 靜態頁面；遊戲不需要遊戲伺服器或網路連線即可遊玩。
