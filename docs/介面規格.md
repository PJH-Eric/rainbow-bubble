# 彩虹泡泡砲 — 模組介面規格（給分工產出用）

專案根目錄：`C:\Eric\AI Agent\rainbow-bubble`（在 device_bash 裡是 `$HOME/mnt/AI Agent/rainbow-bubble`）。
零依賴：不用 npm 套件、不用外部圖檔、不用 emoji 文字當美術；全部是程式產生的向量 SVG 字串。
所有檔案一律 **UTF-8（無 BOM）、LF**，註解與文字用繁體中文。
全部檔案採 UMD 寫法：`(function (root) { 'use strict'; ... root.Art = root.Art || {}; ... })(typeof self !== 'undefined' ? self : this);`
需要在 Node 測試的檔案（layouts.js）另外 `if (typeof module !== 'undefined' && module.exports) module.exports = ...;`

## 2. 地圖字元格式（layouts.js 與 rules.js 共用）

一張地圖 = 字串陣列，每個字元一格。**偶數列（第 0、2、4… 列）長度 = 欄數 W，奇數列長度 = W-1**（六角交錯，奇數列向右偏半格）。

| 字元 | 意義 |
|---|---|
| `.` | 空格 |
| `a`～`f` | 顏色槽 1～6（同一個字母=同一種顏色；槽會被亂數對應到本局使用的顏色，所以一張圖在不同局顏色會不同，但「誰跟誰同色」不變） |
| `A`～`F` | 同上，並且帶「星星標記」（被消除或掉落時，會連帶炸掉周圍 6 顆） |
| `#` | 隨機顏色 |
| `*` | 隨機顏色＋星星標記 |
| `+` | 隨機顏色＋獎勵標記（被消除算 3 顆分數） |
| `X` | 雲朵磚：消不掉、永遠算黏在天花板上的固定障礙 |

規則：
- 手設地圖以 **W=10** 撰寫（偶數列 10 字、奇數列 9 字），列數 5～10 列。
- 第 0 列至少要有一個非空格；**每一個非空格必須能經由相鄰的非空格連回第 0 列**（不然開局就會掉下來）。
- `X` 也算連到天花板的支點，但 `X` 本身不能是唯一支點之外的孤島；`X` 的總數不超過全部格數的 20%。
- 幼幼班不使用含 `X` 的地圖（資料上用 `obstacle: true` 標記）。

## 3. layouts.js 介面（Node 與瀏覽器都能載入）

```js
Layouts.PATTERNS   // [{ id, name, group, rows:[字串…], obstacle:boolean, special:boolean }]  至少 40 張
Layouts.FAMILIES   // 程序生成家族 [{ id, name, gen(rng, cols) -> rows }]  至少 8 種
Layouts.list()                       // 回傳 [{id,name,group,obstacle,special,kind:'pattern'|'family'}]
Layouts.resolve(idOrRandom, opt)     // idOrRandom: 地圖 id 或 'random'；opt = { cols:8|10|12, rng:()=>[0,1), noObstacles:boolean }
                                     // 回傳 { id, name, cols, rows:[字串…] }；rows 已經重採樣到 opt.cols，偶數列長 cols、奇數列長 cols-1
Layouts.resample(rows, cols)         // 把 W=10 的手設地圖重採樣成其他欄數（用「相對 x 位置取最近格」）
Layouts.validate(rows, cols)         // 回傳 { ok:boolean, problems:[字串] }（列長、字元合法、連回第 0 列、X 比例）
```
- `rng` 是可注入的亂數（rules 用 seed 亂數傳入）；**同樣的 rng 序列必須得到同樣的結果**。
- `noObstacles` 為 true 時，`X` 一律換成 `#`（隨機色），且不會挑中 `obstacle:true` 的地圖。
- 隨機挑圖時：手設 70%、程序生成 30%。

## 4. 美術介面（全部掛在全域 `Art` 物件上，檔案要用 `root.Art = root.Art || {}` 合併）

### art-dragons.js — 8 隻原創可愛龍
```js
Art.DRAGONS                    // [{ id, name, accent }] 共 8 隻，順序固定
Art.dragonSVG(id, pose)        // 完整 SVG 字串，viewBox="0 0 200 200"；pose = 'idle' | 'shoot' | 'cheer' | 'sad'
Art.dragonFaceSVG(id)          // 只有頭部的頭像 SVG，viewBox="0 0 100 100"，用在名單、聊天、結算
```
### art-world.js — 泡泡、特殊物件、發射器、六套背景、標誌
```js
Art.COLORS                     // [null, {id:1,name:'紅',main:'#ff5c7a',shape:'heart'}, …] 長度 7（索引 0 空）
Art.bubbleSVG(colorId, opt)    // opt={mod:0|1|2}；mod 1=星星標記、2=獎勵標記；viewBox="0 0 100 100"；半透明立體球＋高光＋反光＋顏色專屬圖案
Art.specialBubbleSVG(kind)     // kind='rainbow'|'star'（發射用特殊泡泡）|'cloud'（雲朵磚 X）；viewBox="0 0 100 100"
Art.cannonSVG()                // 彩虹砲，砲管朝上，viewBox="0 0 100 160"，旋轉中心在 (50,110)
Art.THEMES                     // 六套主題 [{ id, name, sky:[上色,下色], frame:[亮,暗], boardFill, boardLine, accent, music:'a'~'f' }]
Art.themeBgSVG(themeId)        // 滿版背景 SVG（viewBox="0 0 1600 900" preserveAspectRatio="xMidYMid slice"），有多層景物（遠景、中景、裝飾）
Art.logoSVG()                  // 遊戲標誌「彩虹泡泡砲」，viewBox="0 0 520 200"
Art.icon(name, size)           // 介面小圖示（stroke=currentColor, viewBox 24）；至少含：gear home back close chat copy crown play plus minus check eye user link music sound vibrate help refresh trash robot pause flag list trophy swap target users
```
主題 6 套（順序固定）：0 彩虹草原、1 暖暖海灘、2 糖果山、3 童話森林、4 星星夜空、5 海底世界。

## 5. 畫面約定
- 泡泡半徑單位 R=1；渲染器會把 SVG 光柵化成貼圖快取，所以 SVG 不能依賴外部資源、不能用 `<foreignObject>`、不能用 CSS 變數。
- 同一個 SVG 字串裡若有 `id`（漸層等），請加上唯一前綴（例如 `bub3-`），避免同頁多張 SVG 衝突。
- 美術風格：明亮、飽和、圓潤、立體（漸層＋高光＋柔和陰影），粗細一致的深色描邊。
- 「要能清楚辨別避免玩家誤判」：6 種泡泡的顏色加圖案要一眼分辨，圖案在小尺寸（20px）下仍可辨識。
